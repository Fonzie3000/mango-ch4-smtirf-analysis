# mango-ch4-smtirf-analysis

Analysis code for Chapter 4 of the PhD thesis "Fluorogenic RNA Mango Aptamers: Single-Molecule Characterisation and Applications in CRISPR-Mediated Genomic Imaging" (Fangqi Liu, Imperial College London, 2026).

## Scope
1. TCSPC analysis: reading DAS files and fitting fluorescence decays to extract lifetimes
2. smTIRF trace analysis: single-molecule localisation, trace extraction, and change-point detection (CPD) fitting of traces
3. smTIRF kinetic analysis: dwell-time and rate analysis of the idealised traces
